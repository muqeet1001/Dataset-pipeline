The fabric pattern remains full width at the ankles. Separate springs gather

Run from the repository:
  python run_clothing.py --preset reference --contact-every 4
Or double-click RUN-REFERENCE-CLOTHING.cmd on Windows.

Reopen existing outputs without starting simulation:
  python run_clothing.py --preset reference --view-only

The CPU preview applies supplemental sampled body contact once per four
Newton substeps. Newton still evaluates its contacts every substep. Use
--contact-every 1 to apply the supplemental correction every substep, then
compare the actual quality reports. The validation tolerances are unchanged.
This option is a scheduling choice, not an established speed/accuracy result.

Each fit exports its actual cloth trajectory, final GLB/OBJ, flat pattern data,
elastic data, provenance and independent collision/strain/settling report.
Bad fits remain needs_review and are not labelled training ready. The viewer
must display each actual result rather than rescale one outfit into four sizes.

The turntable rotates the rendered view. It does not animate the body or
simulate cloth on moving arms. Matching the reference's articulated motion
remains unfinished. Fabric calibration and a validated all-fit dataset run
also remain unfinished; a matching colour/render does not establish these.

  No visible holes, body crossings or shirt/trouser crossings in a full turn.
